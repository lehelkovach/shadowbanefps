SB_CastShout.wav — theurgic cast invocation (facsimile)
=======================================================

Not ripped from Shadowbane (copyrighted game audio).

What it is meant to evoke
-------------------------
Players remember Shadowbane casts as a stretched "ATAHHHH!".
That tracks theurgic / Golden Dawn Kabalistic Cross vibration of
Hebrew ATAH (אתה, "Thou") — often spelled Ateh in GD texts —
elongated on a full breath: AAAAHHH–TAAAAAH
(Llewellyn / ritual practice: AH-TAH fully exhaled).

This file is an original Windows TTS stand-in ("Awwwwww tahhhhhhhh")
plus a procedural PCM fallback in code if the WAV is missing.
Replace with a licensed or original VO take when available.
